# 一页 PPT 要点（GNN-DSDP demo）

> 用途：组内汇报 1 页；每页配的图都在 `$GNNSITE_HOME/results/`（需 VS Code Remote 打开）。

## 要点 1：做了什么

DSDP 的位点预测原来是 3D-CNN（PUResNet）输出 2 Å 体素概率；本次把它换成**残基级 GCN**，
每个残基输出一个"配体结合概率"，再转成对接盒子，接回 DSDP 原有 CUDA 对接引擎。
下游对接二进制**一行没改**，只换了"盒子从哪来"。

## 要点 2：数据与切分（不给网络下载留口子）

PDBBind v2020 全量包（19,443 复合物）已在本机；用 EquiBind 的 time split：
**train 16,379 / val 968 / test 363**，实测覆盖率 **100%**，三个集合互斥。
标签 = 残基重原子与配体重原子 ≤5 Å。
→ 配图：无（表格）

## 要点 3：模型很小，先跑通

4 层 GCN：46→38→28→18→8→2，**3,570 参数**，ELU + log_softmax + NLLLoss（pos_weight≈22）。
全量训练 100 epoch 只用 **12 分钟**（RTX 4090），best epoch 92。
→ 配图：`fig_training_curve.png`

## 要点 4：残基级指标（主表）

test 363（130,222 残基）：
| 方法 | ROC-AUC | PR-AUC |
|---|---|---|
| DSDP·Cα 单点体素 | 0.8636 | 0.3204 |
| DSDP·3×3×3 邻域 | 0.9075 | 0.4925 |
| **GNN** | 0.8853 | 0.4049 |
| GNN·1-hop 平滑 | 0.8464 | 0.2487 |
→ 配图：`fig_table1_auc.png`
→ 口播：GNN 比"单点体素"强，但**没有超过**"邻域"口径，这是最重要的一句实话。
→ 补充列：DUD-E 102 靶点（另一套考场）GNN **PR 0.5326 / ROC 0.9141**，说明模型本身有效。

## 要点 5：端到端才见真章

从 test 363 分层抽 40 个（按 GNN top-20 命中率分高/中/低），两条管线用同一套 DSDP 参数（384×40）：

| 管线 | 成功率 RMSD<2 Å | 中位 RMSD |
|---|---|---|
| GNN 盒子 | **13/40 = 32.5%** | 5.72 Å |
| DSDP 原版 | **16/40 = 40.0%** | 4.58 Å |
→ 配图：`fig_e2e_rmsd.png`
→ 口播：差距主要在"口袋选错"（GNN 6/40 盒子没罩住），不在盒子大小；
6kqi 这种 case GNN 32.9 Å 而 DSDP 0.8 Å。

## 要点 6：盒子质量（为什么是 36 Å / 阈值 0.5）

盒子参数**只在 val 968 上选**：阈值 0.5、边长 36 Å、概率加权质心、单链接 8 Å。
val 上 **79.0%** 复合物配体覆盖 ≥90%；test 一次性报告 **82.1%**，中心误差中位 **10.5 Å**。
→ 配图：`fig_center_error_hist.png`

## 要点 7：几个具体例子（成功与失败）

- 成功：6g2o（RMSD 0.20 Å）、6jao（0.21 Å）、6qqw（0.22 Å）
- 失败：6kqi（GNN 32.9 Å / DSDP 0.8 Å）、5zk7（两条线都 32+ Å）
→ 配图：`viz/6jao_pocket.png`、`viz/6kqi_pocket.png`
→ 口播：红点是 GNN top-20 残基，绿是晶体配体，蓝是对接 pose。

## 要点 8：结论与下一步

- 管线已完全跑通（数据→特征→图→训练→盒子→对接→RMSD→图表），**可复现**。
- 局限：没有赢基线；概率未校准（mean 0.23 vs 真实 4%）；盒子中心 10.5 Å；DUD-E 未做。
- 下一步（如果还要做）：特征加 PLM 嵌入 / 换成 EGNN、把"选口袋"单独做分类、
  用 30~50 个蛋白的 RMSD 做真正的端到端调参目标。
